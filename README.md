# ☾ ALXZ// — Digital Studio

> 03:00 — somewhere between code & imagination.

**En vivo:** https://alxz-studio.netlify.app · Repositorio: https://github.com/AlxzDiaz/alxz-studio

Cada `git push` a `main` se publica solo en Netlify.

Sitio estático (HTML + CSS + JS, sin dependencias) construido a partir de `ALXZ_BRIEF_MAESTRO_CLAUDE.md` y `ALXZ_identidad.md`.

```
index.html          Hero · About · Projects · Services · Contact · Footer
css/styles.css      Tokens de color/tipografía al inicio (:root)
js/main.js          Nav, menú móvil, reveal al hacer scroll, parallax leve
images/projects/    Capturas reales de los 8 demos (escritorio para el sitio, celular para Instagram)
instagram/         Kit de Instagram (ver instagram/textos.md)
```
